Mac Stitch Drop GitHub

Send embroidery designs from your Mac to your Brother machine

Over Wi‑Fi, with no USB stick and no Windows PC. Right-click a file in Finder, or send straight from Ink/Stitch.

Get it on GitHub See the four ways to send

Free and open source (MIT). Tested on the Brother SE700.

Four ways to send

Install whichever fits how you work, or all four. They share one saved machine, so once one of them finds your machine, they all know it.

From Finder

Right-click, Send to Brother

Select files, right-click, and choose Quick Actions → Send to Brother. It finds your machine, shows what will be sent and what won’t, then sends when you press Send.

  • Sends .pes .dst .phc .phx .pen as they are
  • Ink/Stitch .svg files are stitched for you first
  • Several files at once
bash install.sh quickaction

From Inkscape

Send straight from Ink/Stitch

Finish a design and choose Extensions → Ink/Stitch → Visualize and Export → Send to Brother Machine. No saving, no exporting, no file to find.

  • Find your machine, then send: two steps in one window
  • Checks the design fits your hoop before it goes
  • Send only the selected objects if you like
bash install.sh inkstitch

From the Dock

A window you drop files on

Click StitchDrop in your Dock. It finds your machine, shows how much memory is free, and sends whatever you drop on it.

  • Built on your Mac by the installer, so macOS doesn’t block it
  • Quits by itself when you close the window
bash install.sh app

From Terminal

The stitchdrop command

Scan for machines, check free memory, and send files from a script. Handy for automation and for troubleshooting.

bash install.sh cli

Command-line guide

$ stitchdrop scan
Scanning 192.168.1.0/24 (254 addresses)…
  ✓ 192.168.1.50  name='SE700'  fw=1.10

$ stitchdrop send 192.168.1.50 driver-cover.pes
  ✓ sent driver-cover.pes (14,322 bytes)
Done. On the SE700, open the embroidery screen
and pick the Wi-Fi/received designs.

How sending works

Every tool follows the same two steps.

  1. Find your machine

    It tries the machine you used last. If that one doesn’t answer, it searches your Wi‑Fi for Brother machines. You can also type the IP address the machine shows under Settings → Wireless LAN.

  2. Check and send

    Before anything goes over, it checks the design against the machine: does it fit the hoop, and is there enough memory? Then it sends, and you choose the design on the machine’s embroidery screen.

Talks to the machine directly

It uses the same local Wi‑Fi protocol as Brother’s Windows-only Design Database Transfer app. Nothing goes through the cloud.

Remembers your machine

One saved machine is shared by all four tools, in ~/.stitchdrop.json.

Uses your Ink/Stitch

.svg designs are stitched by your own Ink/Stitch, so they come out exactly as Save As → PES would make them.

Install

Open Terminal and run:

$ git clone https://github.com/george-vice/mac-stitch-drop.git
$ cd mac-stitch-drop
$ bash install.sh quickaction   # or inkstitch, app, cli, all

No git? Download the ZIP, unzip it, and run the last line from inside the folder.

You’ll need

  • macOS 11 or newer with Python 3. Your Mac offers to install it the first time you type python3 in Terminal.
  • A Brother or Baby Lock Wi‑Fi embroidery machine that works with Brother’s Design Database Transfer app. Tested on the SE700.
  • For .svg designs: Inkscape with Ink/Stitch.

The first time you send, macOS asks to allow access to devices on your local network. Choose Allow, or your machine can’t be found.
