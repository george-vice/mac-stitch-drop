# Finder Quick Action: Send to Brother

Right-click embroidery files in Finder and send them straight to your machine.

## Install

From the repo folder:

```bash
bash install.sh quickaction
```

The installer puts two things in your home folder:
- **The Quick Action:** `~/Library/Services/Send to Brother.workflow`
- **Its scripts:** `~/Library/Application Support/StitchDrop/quickaction/`

## Use

1. Select one or more files in Finder. You can mix file types.
2. Right-click, then choose **Quick Actions → Send to Brother**.
3. **Step 1: find the machine.** It uses your saved machine if it answers. Otherwise it searches your Wi-Fi network and shows a notification while it looks.
   - If it finds several machines, you pick one from a list.
   - If it finds none, choose **Search again** or **Enter IP…**.
4. **Step 2: confirm.** A dialog lists what will be sent (✓) and what won't (✗), with the reason for each. For example: "Too big: 160 × 40 mm, the hoop area is 100 × 100 mm".
5. Click **Send**. You can also click **Change machine…** or **Cancel**.

A notification confirms when the files are sent. Then, on the machine, open the embroidery screen and choose the design.

| File type | What happens |
|---|---|
| `.pes` `.dst` `.phc` `.phx` `.pen` | Sent as is. |
| `.svg` (Ink/Stitch design) | Your installed Ink/Stitch generates the stitches, then the result is sent as `.pes`. |
| Anything else | Skipped, with a note in the dialog. |

The machine is saved only when you press **Send**. The setting is shared with the other tools in `~/.stitchdrop.json`.

## Troubleshooting

- **"Send to Brother" isn't in the menu.** Right-click any file → **Quick Actions → Customize…**, then tick **Send to Brother**. You can also find it under System Settings → Keyboard → Keyboard Shortcuts → Services → Files and Folders. Logging out and back in also refreshes the menu.
- **It can't find the machine.** Make sure the machine is on and connected to the same Wi-Fi as your Mac. If macOS asked about local network access, allow it. Or choose **Enter IP…**.
- **It asks to install Python 3.** Open Terminal, type `python3`, press Return, and click **Install**.
- **The `.svg` says Ink/Stitch wasn't found.** Install Ink/Stitch, or add `"inkstitch_path": "/path/to/inkstitch"` to `~/.stitchdrop.json`.
- **Logs** are in `~/Library/Logs/StitchDrop.log`.

## Uninstall

```bash
rm -rf ~/Library/Services/"Send to Brother.workflow" ~/Library/Application\ Support/StitchDrop/quickaction
```

## For developers

`Send to Brother.workflow` is generated by `build_workflow.py`. Edit the shell snippet in that file, then run `python3 quickaction/build_workflow.py` to rebuild the bundle. The Quick Action runs `brother_quicksend.py`, which uses `core/stitchsend_core.py` and shows native macOS dialogs through `osascript`.
